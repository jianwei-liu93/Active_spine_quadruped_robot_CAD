## Result and bounded corrections

The adapter follows the correct source-local/physical-instance separation and uses the existing exact prescribed-motion/regeneration APIs. The frozen inventory supplement is exact. Resolve the following metadata/evidence gaps before claiming complete AX0/AX1 acceptance; none calls for mechanical geometry changes.

1. **P2 — Capture explicit closure residuals in each AX1 frame report.** `src/animation_pose_export.py:169–214` records vertex placement errors and selected spine bore-center discrepancies, but does not assert/report `kinematics.residuals(state,p)` or the four legs' `geometry.loop_residuals_mm`. These are different checks. docs/20 AX1 and its current assignment explicitly require linkage closure/residual evidence. Add finite residual maxima and tolerances per sample using the already computed state. Independent pure numeric evaluation of the exact three planned samples found no closure failure: spine maxima 7.11e-15, 5.33e-15, 5.33e-15 mm; leg loop maxima 1.07e-14, 3.55e-15, 3.97e-15 mm; minimum spine feasibility margin 3.198 mm. These calculations are not native runtime results.

2. **P2 — Complete or explicitly mark incomplete procedural ownership/provenance.** `_spring_record` resolves both real owner bodies and local/world anchors correctly: extension O2→InputHorn and O3→shank; compression O1→thigh and A→Foot. `_cable_record` exports the actual ordered line/arc route, world tangent data and ankle-eye owner, but no wheel-terminal or shell/hip-guide owner IDs/local guide points. A module name/“authoritative generator” turn-policy string is not a generator-version or geometric-parameter hash; current spring records also omit exact pitch/turn parameters. Add these bounded records, including appropriate named rigid instances and per-frame request/generator hashes, or state that this part of docs/20 §6 is incomplete. Do not infer that the existing manifest is sufficient for downstream coil reconstruction merely because native source regeneration succeeded. The existing ten procedural records and the native regeneration checks are useful AX1 prototype evidence; full animation sampling remains AX3.

3. **P2 — Correct directly driven hip classification.** At exporter line155 only `axialrot` and `tendon_r03_wheel` become `active`. Actual `foreL/foreR/hindL/hindR_InputHorn` entries are `leg_r02_segment`, so all four directly driven hip horns are exported as passive, while spine horn-gap washers become active. Classify actuator/input ownership explicitly; keep passive knees separate. This does not change the six-command vector or mechanical FK.

4. **P2 — Validator acceptance is weaker than its procedural-state claim.** `animation_manifest_validate.py:243–250` checks duplicated knee values but not the duplicated hip values against the six commands. Lines288–305 require procedural identity/generator/frame only and accept an unknown generator with no anchors, lengths or route. Reproduced with the valid test fixture: changing `leg_angles_rad.foreL[0]` to123 while leaving its commanded hip unchanged still passes; replacing each procedural record with only instance/frame and `generator="nonexistent"` also passes. Add focused consistency checks and typed current spring/cable record requirements if the validator is to certify these metadata. Alternatively narrow its stated guarantee to numeric transform/identity validation and independently assert procedural fields in the exporter. This is not a request for AX2–AX4.

An initial unconditional blocker was found and corrected during review: exporter `axis_mapping` was a numeric identity matrix while validator/schema required the string `"identity"`. Current inspected source uses the required string; this finding is resolved.

- There are **107 distinct LinkedObject source definitions** across the486 instances. The95 native Body count is a separate inventory quantity. Instance IDs use immutable App::Link names; mesh/source references use source names; sorted instance order is explicit. Labels do not determine identity.
- The exporter rejects nonidentity source/shape placements, `LinkTransform=true` and nonunit scalar instance scale for this supported model. It uses `plan.placements[name]` once on local source or regenerated local geometry. The independent comparison side is the existing `copied_shapes` world copy: rigid copies use `newPlacement * oldLinkPlacement.inverse() * oldWorldShapePlacement`; regenerated sources use their matching placement once. Thus the old instance transform is cancelled, rather than applied twice. Raw source vertices under the requested placement are checked against these world vertices at all three samples, and neutral vertices additionally against native `obj.Shape`. This is a substantive numeric proof once actually run, not a mesh/Blender proof.
- Millimetre matrices keep rotation unchanged; metre matrices scale only translation by.001 and are tested with local vertices converted by.001 once. Validator checks homogeneous rows, finite numbers, SO(3), quaternion/matrix agreement and adjacent quaternion signs. It requires sorted complete unique IDs and exactly three distinct ordered samples.
- The exported command vector contains spine phase, four hips and hind wheel; four knees remain named prescribed state with `PRESCRIBED_KINEMATIC`. No extra knee actuators or loaded gait prediction is claimed.
- `leg_motion_r07.descriptor` uses the unchanged exact r03 spine/leg placement machinery and current r07 terminal routes. `regenerate_sources` generates private local shapes with exact request-key caching and copies; compression-qualified cached BREP reuse verifies generator, exact length and BREP hashes. Springs/cables are not affinely stretched. Guide travel and supported tendon hardware states fail closed. Fixed source hashes in the manifest are neutral references, not replacement per-frame deforming meshes.
- The adapter takes pre/post document snapshots and checks canonical file SHA unchanged before writing only handoff/report artifacts. Its explicit limits correctly say three prescribed poses, no loaded equilibrium, no new clearance campaign, no meshes/Blender/video and AX2–AX4 NOT_RUN. Runtime reports must remain NOT_RUN until installed-MCP execution actually returns successfully.
